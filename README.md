# 🌿 Healthy Habit Tracker

A lightweight, interactive web application designed to help users build, track, and maintain healthy daily habits with smooth visual feedback and progress tracking.

🌐 **Live Demo:** [https://healthy-habit-tracker-problem.kleap.io](https://healthy-habit-tracker-problem.kleap.io)

---

## ✨ Key Features

- **Habit Tracking & Management:** Create, customize, complete, and manage your daily habits with intuitive controls.
- **Progress Insights & Analytics:** Track your consistency and view progress over time with dedicated analytics views.
- **Daily Guidance & Tips:** Integrated wellness advice and actionable strategies to build lasting daily routines.
- **Smooth UI Animations & Transitions:**
  - Dynamic completion animations and visual visual feedback when marking habits done.
  - Interactive page transitions and responsive hover effects for UI elements.
  - Animated progress meters and status updates for an engaging user experience.
- **Responsive Layout:** Optimized with clean CSS styling to ensure a seamless experience on mobile, tablet, and desktop devices.
